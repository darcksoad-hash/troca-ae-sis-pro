# Sugestoes de layout para o Troca Ae SIS PRO

## O que ja foi melhorado
- Sidebar mais clara e moderna.
- Logo da Troca Ae aplicada no menu.
- Cor principal em laranja da marca.
- Header em formato de barra moderna.
- Cards com sombra mais suave.
- Navegacao ativa mais destacada.
- Tela de OS em painel operacional com lista e detalhe.
- Acoes de OS sempre visiveis no detalhe: editar, pagamento, finalizar e imprimir.
- Impressao de OS com layout mais profissional.
- Indicadores visuais por cor de status.
- Tema claro/escuro configuravel.
- Campos, botoes e paineis mais arredondados e limpos.

## Sugestoes para a proxima etapa visual
1. Criar tela de login com logo grande e cores da marca.
2. Criar dashboard com graficos reais de faturamento, OS por status e estoque baixo.
3. Criar visual de kanban para OS: Aberta, Diagnostico, Aprovacao, Execucao, Finalizada e Entregue.
4. Criar modo compacto para uso em balcao, com menos espaco entre linhas.
5. Criar modo tecnico para celular, focado em diagnostico, fotos e pecas usadas.
6. Criar indicadores por cor: atraso, garantia, saldo em aberto e estoque minimo.
7. Criar componentes de filtro fixos no topo das tabelas grandes.

## Melhor melhoria recomendada agora
Criar uma tela de login e iniciar a separacao por perfis reais. Isso prepara o sistema para sair do prototipo e virar produto de producao.
